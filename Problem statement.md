1)Title: Movies & Web Series Review and Rating Platform with AI Recommendations
2)Domain: Artificial Intelligence & Data Science
3)User
- Create an account and log in
- Search for movies and web series
- Read and write reviews
- Rate content
- Get personalized recommendations
  Admin
- Manage users
- Manage movies and web series
- Review and remove inappropriate content
4) What problem are we solving?
  usually users visit multiple websites to compare ratings and reviews before a watch.
  Different platforms provide different ratings, so it is difficult to choose the best one .Based on user interests,
  This project combines reviews and ratings in one platform with AI recommendation
5) Proposed Solution:
- User Registration and Login
- Search Movies and Web Series
- Browse by Genre, Language and Release Year
- Submit Ratings and Reviews
- View Average Ratings
- AI-Based Personalized Recommendation System
- User Profile Management
- Admin Dashboard for Content Management
6). Core Entities / Database Tables 
1. Users
2. Movies
3. Web Series
4. Reviews
5. Ratings
6. Recommendations
7. Genres
